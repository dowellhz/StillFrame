# Global agent instructions

## macOS 图形应用

- 在 macOS 上，第三方 `.app` 图形程序必须默认通过 LaunchServices 启动；不要从受限终端或沙盒直接执行 `AppName.app/Contents/MacOS/*`。
- 通过 LaunchServices 启动，例如：`open -a AppName --args ...`。这条规则适用于 Blender、Bambu Studio、切片软件、CAD 软件以及其他依赖 Metal、窗口服务器或 GUI 会话的程序。
- **禁止使用 `open -n` 或 `open -na` 连续启动自动化任务**；`-n` 会强制创建新的应用实例，容易留下大量未关闭窗口。优先复用现有实例。
- 即使应用提供命令行参数，只要其可执行文件属于 `.app` 包，也先按 GUI 应用处理；除非官方明确提供独立、纯 headless 的 CLI，并且已确认不依赖 GUI、Metal 或窗口服务器。
- 自动化脚本通过绝对路径传给应用；需要诊断时让脚本写日志文件，并通过输出文件或日志判断完成状态。
- 启动后只轮询预期输出或日志，不要为了检查进度反复启动同一个应用实例。
- 自动化任务完成后，如果应用是本次任务自动启动且用户没有在其中进行手动操作，应主动正常退出该应用；若无法确认，先询问或只关闭本次创建的窗口，不要累积后台实例。
- 若直接启动曾异常退出，不要重复尝试相同方式；改用 LaunchServices，并向用户说明原因。
