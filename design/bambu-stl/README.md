# Stillframe 拓竹打印件（原型版）

单位均为毫米，STL 可直接导入 Bambu Studio。

## 零件

1. `01-main-shell-upper.stl`：屏幕保护罩上半。
2. `02-main-shell-lower.stl`：屏幕保护罩下半。
3. `03-controller-board-tray.stl`：开发板独立托盘。
4. `04-seam-joiners-two.stl`：两条背面接缝加强片。

## 建议打印参数

- 材料：首版建议 PLA；长期使用可改 PETG。
- 喷嘴：0.4 mm。
- 层高：0.20 mm。
- 墙层：3 道。
- 顶层/底层：至少 6 层。
- 支撑：关闭。
- 摆放：所有零件大平面贴热床。
- 主罩建议加 5 mm 外沿，避免长边翘曲。

## 装配

- 主罩两半对齐后，在外侧背面粘贴两条加强片。
- 开发板托盘确认排线和 USB-C 位置后，再粘到主罩背面。
- 两个螺丝柱按照照片估算，使用 M3 自攻螺丝，预留孔径 2.8 mm。
- 屏幕排线不可带电插拔，也不要在排线折弯处施加胶水或压力。

## 打印前必须复核

- 开发板两个大孔的中心距，目前估算为 52.2 × 81.5 mm。
- USB-C 中心和插头外壳尺寸。
- 实物屏幕加保护膜后的总厚度。

这是按现有厂家图纸和照片制作的装配原型；孔位尚未经过卡尺实测。
