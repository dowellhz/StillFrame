# Stillframe X2D 两片版 STL

针对 Bambu Lab X2D 256 × 256 mm 打印区域制作。

## 主保护罩

- `01-shell-top.stl`：上片。
- `02-shell-bottom-fpc-slots.stl`：下片，包含一个排线孔和左右承重卡台。

主罩拼合后约233.6 × 339.25 mm。上下两片分别打印，每片基础尺寸约233.6 × 169.63 mm；上片带搭接舌后最大高度约177.63 mm。

## 附件

- `03-controller-board-tray.stl`：开发板托盘。
- `06-controller-case-bottom.stl`：仅容纳开发板的底盒；左侧合并开口同时服务USB-C与SD卡，顶部保留屏幕排线口，并带两侧卡扣锁止凸台。
- `07-controller-case-lid.stl`：独立薄盖板，带定位内沿和左右弹性卡扣，无需螺丝或胶水。
- `08-controller-case-and-lid.stl`：底盒和盖板同盘排列版本，不包含连接板。

## 结构

- 卡纸粘贴边宽12 mm，在保留粘贴面积的同时增加打印盘边界余量。
- 屏幕凹槽深约1.4 mm，外形总间隙约0.8 mm。
- 接缝只保留3个18 × 8 mm插片负责定位，结构保持简单。
- 底部只保留一个38 × 3 mm圆头排线孔；在原34 mm基础上两端各增加2 mm。
- 左右承重条托住屏幕底边，并分别直接连接左右边框；左侧长度约27.45 mm，与排线孔之间仍留出约10.24 mm折弯空间。

## 打印建议

- 使用X2D主喷嘴；辅助喷嘴可打印区域较窄，不适合233.6 mm宽的主罩。
- 0.4 mm喷嘴、0.20 mm层高、3道墙、至少6层底层。
- 大平面朝向打印盘，不需要支撑。
- 主罩两侧合计留约22.4 mm打印边界，可使用X2D标准工艺的自动Brim。
