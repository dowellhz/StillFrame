# Stillframe 界面原型

此目录是误按“浏览器流程模拟器”理解后做出的早期界面原型，不执行 ESP32 固件，也不能用于 ROM、屏幕驱动或 OTA 的真实验证。

用户已明确需要能够加载真实固件的 ESP32 仿真环境，后续工作以 [emulator](../emulator/README.md) 为准。本目录暂保留用于界面讨论，不继续作为固件模拟器开发。

Stillframe模拟器.html 是离线页面原型，public 和 server.mjs 是对应的浏览器与 Node 服务代码。它们的设备状态来自 JavaScript，升级演示也是流程动画；不代表运行真实固件。服务端有三组内存请求测试，但前端完整交互尚未完成验收。
