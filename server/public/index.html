升级相框 ROM

设备下次联网时领取任务（默认每小时）。设备再次核对型号、容量与 SHA-256，写入备用分区并重启。启动失败会回退原版本。取消任务无法中止已经开始写入的升级。

连接你的 Stillframe

  1. 在相框首次开机时，连接它的配网热点。
  2. 打开相框配置页，填写家中 Wi-Fi。
  3. 将以下服务器地址和接入凭证填入相框。

相框需要使用能访问本服务的局域网地址或域名；不能填写 localhost 或 127.0.0.1。

凭证用于设备访问，和管理员登录密码不同。服务器收到首次有效请求后自动建立设备档案。
